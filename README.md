# Graci Kabuya Ngoy Portfolio

A standalone React, TypeScript, Vite, and Framer Motion portfolio. It does not require Replit services or environment secrets.

## Run locally

```sh
pnpm install
pnpm run dev
```

## Verify and build

```sh
pnpm run typecheck
pnpm run build
```

The static site is written to `dist/public`.

## Deploy to Vercel

Import this repository with the repository root as the Vercel project root. The included `vercel.json` configures the install, build, static output, and SPA route fallback.
